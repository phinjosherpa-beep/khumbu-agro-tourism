# Khumbu Agro Tourism Website

This folder is prepared as a static website for free hosting.

## Main file
- `index.html` — website home page

## Images
- `images/` — all website image files

## Before publishing
1. Open `index.html` in a browser and check the website.
2. Keep the `images` folder in the same location as `index.html`.
3. The Contact and Booking forms currently display a success message locally but are not connected to an email/form service. Connect them before relying on them for real enquiries.

## GitHub Pages
Create a GitHub repository, upload the contents of this folder to the repository root, then enable GitHub Pages from the repository's Settings > Pages.

## Netlify
Create a new site and deploy the contents of this folder by drag-and-drop, or connect the GitHub repository.

## Important
Do not rename the `images` folder unless you also update the image paths in `index.html`.
